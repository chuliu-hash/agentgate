# AgentGate 后端实习生学习导航

> 本文是学习入口；完整文档分类请先查看 [文档中心](README.md)。

本套文档面向刚接触 Java 后端的实习生，以当前代码为依据，介绍项目如何启动、请求如何处理及各文件的用途。无需先掌握 RabbitMQ，消息章节从交换机、队列和确认机制讲起。

## 推荐阅读顺序

1. [运行环境与总体架构](learning-01-runtime-architecture.md)：业务目标、组件职责、分层概念、环境准备和启动过程。
2. [身份认证与完整请求链路](learning-02-request-flow.md)：Redis Token 与 AK/SK 的区别，沿一次工具调用理解过滤器、签名、转发和响应。
3. [数据模型、状态流转、缓存与限流](learning-03-data-cache.md)：八张表、并发条件更新、缓存重建、Lua 令牌桶和日/月配额。
4. [消息队列、安全实现与调试实践](learning-04-messaging-security.md)：从零理解 RabbitMQ、ACK、死信、幂等和事务，再学习 SSRF、脱敏、审计、异常和排错。
5. [逐文件源码讲解](source-walkthrough/README.md)：按八个模块收录 111 个文件的用途、字段/方法声明及完整代码，覆盖生产源码、测试、资源、构建与脚本。

## 怎样使用这套文档

第一遍沿上述顺序理解流程，不必背所有类名。第二遍在 IDEA 打开文中提到的类，对照字段、方法和完整源码设置断点。第三遍运行现有测试和本地演示，观察 Redis 数据、数据库记录和消息消费。

源码讲解中的代码是编写时的快照。发生修改时以仓库真实源文件为准，同时维护相关文档。说明中特别区分已实现行为与边界：例如配额脚本只保证 Redis 内扣减原子、上游失败不退额度，消息发送成功不保证最终落库，DNS 地址检查不等于完全阻止 DNS 重绑定。
